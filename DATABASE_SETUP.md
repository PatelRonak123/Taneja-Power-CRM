# Database Architecture & Migration Setup

This document outlines the database architecture, schema management, migration workflow, and seeding procedures using **PostgreSQL** and **Drizzle ORM**.

---

## 1. Database Overview

- **Engine**: PostgreSQL (v14+)
- **ORM**: Drizzle ORM (`drizzle-orm`)
- **CLI & Migrator**: Drizzle Kit (`drizzle-kit`)
- **Driver**: `pg` (node-postgres connection pooling)

---

## 2. Directory Structure

```text
server/
├── drizzle/                     # Versioned SQL migration files generated by Drizzle Kit

│   └── meta/

│       └── ...

├── src/

│       ├── schema/              # TypeScript schema definitions
│       │   ├── index.ts         # Schema barrel export
│       │   ├── users.ts         # Users & authentication table
│       │   └── products.ts      # Products & inventory table
│       │
│       ├── relations/           # Drizzle table relations
│       │   └── index.ts
│       │
│       ├── db.ts                # PostgreSQL connection pool & Drizzle instance
│       ├── migrate.ts           # Programmatic migration executor
│       └── seed.ts              # Database seeder script
│
└── drizzle.config.ts            # Drizzle Kit CLI configuration
```

## 3. Migration Policy & Workflow

> [!IMPORTANT]
> **Strict Migration Rule**: Never use `drizzle-kit push` for standard application development. All database schema changes must follow the migration generation and migration execution workflow.

### Workflow for Schema Changes

1. **Edit Schema**:
   Update or create schema files in `server/src/database/schema/`.

2. **Generate Migration**:
   Run Drizzle Kit to create a new SQL migration file:
   ```bash
   cd server
   npm run db:generate
   ```
   This generates a timestamped SQL migration in `server/drizzle/`.

3. **Review Migration**:
   Inspect the generated SQL file in `server/drizzle/` to verify safety and correctness.

4. **Apply Migration**:
   Apply pending migrations to the active database:
   ```bash
   npm run db:migrate
   ```

## 4. Environment Configuration

Define the following environment variables in `server/.env`:

```env
DATABASE_URL=postgres://postgres:postgres@localhost:5432/taneja_power_db
DATABASE_HOST=localhost
DATABASE_PORT=5432
DATABASE_USER=postgres
DATABASE_PASSWORD=postgres
DATABASE_NAME=taneja_power_db
DATABASE_SSL=false
```

---

## 5. Seeding the Database

To seed initial administration accounts, demo data, and default catalogs:

```bash
cd server
npm run db:seed
```

---

## 6. Production Deployment Migrations

During production deployment or CI/CD pipelines, execute:

```bash
npm run build
node dist/database/migrate.js
```
This executes migrations programmatically and safely exits upon completion.
